# 포트폴리오

## 프로젝트 요약

SOAR는 Salesforce를 운영 플랫폼으로 사용하는 조직을 위해 탐지·정책·대응·감사를 하나의 보안 운영 흐름으로 묶은 관리 패키지 프로젝트입니다.

단순한 이벤트 수집 기능을 만드는 대신, 실제 운영에서 발생하는 다음 문제를 제품 구조에 반영했습니다.

- 서로 다른 보안 신호를 공통 정책 체계로 다루기
- 파괴적 대응에 승인과 롤백 경계 두기
- 외부 채널 장애와 중복 알림을 운영 가능한 방식으로 처리하기
- 설치 후 고객 조직이 직접 켜야 하는 기능을 헬스체크와 설정 화면으로 안내하기
- 일반 사용자에게 운영 권한을 주지 않고 전사 탐지 유지하기

## 핵심 어필 포인트

1. **탐지에서 대응까지 이어지는 운영 제품화**: 대시보드, 정책 매퍼, 라우트, 스케줄러, 감사 원장을 하나의 운영 경험으로 연결
2. **보안 경계를 설계에 내장**: 최소 권한, 이중 승인, 단일 사용 토큰, Named Credential, 킬 스위치와 감사 추적
3. **Subscriber 확장성**: 센서, 업무 로직 평가, Flow, 외부 SIEM/SOAR, 결과 화면을 공개 계약으로 확장
4. **설치 후 활성화 경험**: 패키지 설치와 고객 조직별 설정을 분리하고 Setup & Health Center로 상태를 가시화
5. **검증 가능한 품질 기준**: 기능 평가, 통합 테스트, UI 증빙과 커버리지 기준을 함께 관리

## 공개 자료의 범위

이 포트폴리오는 제품 설계와 검증 방법을 보여주기 위한 자료입니다. 패키지 내부 구현 소스, 고객 조직 식별정보, 인증 정보와 원본 테스트 로그는 포함하지 않습니다.
